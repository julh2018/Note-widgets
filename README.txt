APK বানানোর ধাপ:
1. GitHub-এ একটি নতুন রিপোজিটরি খুলুন এবং এই ফোল্ডারের সব ফাইল (লুকানো .github ফোল্ডারসহ) আপলোড করুন।
2. রিপোজিটরির Actions ট্যাবে যান, "Build APK" রান শেষ হওয়ার অপেক্ষা করুন (৩-৫ মিনিট)।
3. রান খুলে নিচের Artifacts থেকে notes-widget-apk নামান, জিপ খুলে app-debug.apk ইনস্টল করুন।
4. হোম স্ক্রিনে ফাঁকা জায়গা চেপে ধরে Widgets > নোট উইজেট যোগ করুন।
